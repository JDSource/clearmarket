PURPOSE
You are evaluating whether a detected divergence between prediction-market consensus
and an external benchmark (e.g., CME FedWatch, Bloomberg economist median, FRED data)
is editorially worth surfacing as a wire item.

INPUTS PROVIDED
- pm_consensus_24h_vw: volume-weighted PM consensus
- benchmark_value: external benchmark value
- divergence_pp: difference in percentage points
- benchmark_source: name of underlying source
- benchmark_source_url: URL to source
- corr_30d_poly, corr_30d_kalshi: historical correlation with benchmark
- corr_breakpoint_date: when correlation broke (if applicable)

RUBRIC
Return wire_eligible if ALL of:
  1. |divergence_pp| > threshold (typically 5.0pp; varies by benchmark)
  2. Either historical correlation was > 0.7 (so divergence is meaningful)
     OR the benchmark recently moved while PMs did not
  3. The benchmark is from a recognized source (not aggregated rumor)
  4. The PM consensus is volume-weighted on at least $250K/24h combined

Return not_eligible if any of:
  - Divergence exists but historical correlation was always low (uncorrelated)
  - Benchmark source is stale (> 24h) for an event with high catalyst velocity
  - PM volume is below noise floor on both venues

CONFIDENCE
Return judge_confidence in [0.0, 1.0]:
  > 0.85 — clear divergence with established correlation history
  0.70-0.85 — divergence exists but correlation history is shorter or noisier
  < 0.70 — borderline

OUTPUT FORMAT
{
  "judge_verdict": "wire_eligible" | "not_eligible",
  "judge_confidence": <float>,
  "reasoning": "<1-2 sentences>"
}
