WIRE TYPE: cross_venue_divergence
JUDGE MODEL: claude-sonnet-4 family (specific model version locked in /schema/judge/v1)

PURPOSE
You are evaluating whether a detected cross-venue spread between two prediction-market
venues (Polymarket and Kalshi) is editorially worth surfacing as a wire item.

INPUTS PROVIDED
- spread_pp: current cross-venue spread in percentage points
- threshold_pp: detection threshold (typically 5.0)
- percentile_30d: rank of current spread vs trailing 30-day distribution
- prior_max_pp: largest spread observed in last 30 days
- poly_vol_24h_usd, kalshi_vol_24h_usd: trading volume on each venue
- event_question: the underlying event being priced

RUBRIC
Return wire_eligible if ALL of:
  1. spread_pp > threshold_pp
  2. percentile_30d >= 90 (top decile of last 30 days)
  3. AT LEAST one venue has > $250K of 24h volume (signal-vs-noise floor)
  4. The event_question describes a real, scheduled, resolvable event

Return not_eligible if any of:
  - Spread is large but both venues have < $50K volume (noise)
  - Spread is large but one venue is closed/halted/resolved
  - Spread is explained by stale price on one side (no trades > 12h)
  - The event is too poorly specified to support institutional citation

CONFIDENCE
Return judge_confidence in [0.0, 1.0]:
  > 0.85 — high-conviction wire-eligible
  0.70-0.85 — eligible with caveats; surface but flag
  < 0.70 — borderline; defer to next detection cycle

OUTPUT FORMAT
{
  "judge_verdict": "wire_eligible" | "not_eligible",
  "judge_confidence": <float>,
  "reasoning": "<1-2 sentences>"
}
